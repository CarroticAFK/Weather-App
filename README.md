# 🌦️ Weather App

A simple and responsive weather forecasting web application that lets users check current weather conditions and upcoming forecasts for different cities.

## ✨ Features

- 🔍 **City Search** — Search for weather information by city name.
- 📍 **Current Location** — Get weather information based on your location.
- 🌡️ **Current Weather** — View temperature, weather conditions, and other weather details.
- 📅 **Weather Forecast** — Check upcoming weather forecasts.
- 🌅 **Sunrise & Sunset** — View sunrise and sunset times.
- 💨 **Weather Details** — Check humidity, wind speed, and other atmospheric information.
- 🎨 **Responsive Interface** — A clean interface with weather icons and visual elements.

## 🛠️ Technologies Used

- HTML5
- CSS
- JavaScript
- [OpenWeather API](https://openweathermap.org/api)
- [Font Awesome](https://fontawesome.com/)

## ⚙️ Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/CarroticAFK/Weather-App.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Weather-App
   ```

3. Open `index.html` in your browser, or use the **Live Server** extension in VS Code.

4. If required, configure your OpenWeather API key in the JavaScript files before running the application.

## 🌐 Deployment

This application can be hosted using GitHub Pages:

1. Open the repository's **Settings**.
2. Navigate to **Pages**.
3. Select **Deploy from a branch**.
4. Choose the `main` branch and `/(root)` folder.
5. Save and wait for deployment.
